# Franco Panero · Portfolio

Portfolio de **Franco Panero**, Data Scientist en formación como Data Engineer.

🔗 **https://fpanero.github.io**

Una sola página hecha a mano (HTML, CSS, SVG y Canvas, sin dependencias) que se recorre como un flujo de datos: cada etapa es una sección y cada rama una especialidad.

## Editar

- Contenido de cada etapa: `<template id="st-0">` a `<template id="st-8">` en `index.html`.
- Recorrido, ramas y herramientas del mapa: `STAGES`, `BR` y `SEGS` en el script.
- Casos de estudio y artículos del blog: plantillas `caso-*` y `post-*`.

Cada cambio que se sube a la rama `main` se publica solo en GitHub Pages en uno o dos minutos.
